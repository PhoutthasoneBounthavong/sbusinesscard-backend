# SBusinessCard Backend API

AI-powered business card scanner and digital card vault REST API built with FastAPI, Tesseract OCR, and SQLite.

## Deployment on Render
1. Create a new Web Service on [Render](https://render.com).
2. Connect this repository: `PhoutthasoneBounthavong/sbusinesscard-backend`.
3. Render automatically detects the `Dockerfile` at the root and deploys.
4. Health check endpoint: `/api/health`.
